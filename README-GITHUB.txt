========================================
 UPLOAD KE GITHUB PAGES - CV REVA
========================================

LANGKAH (tanpa install, lewat browser):
1) Buat akun GitHub (gratis): https://github.com/signup
   - Bisa pakai "Continue with Google".
2) Buat repository baru:
   - Klik "+" (kanan atas) -> "New repository"
   - Repository name: cv-reva  (atau nama lain)
   - Pilih "Public"
   - Klik "Create repository"
3) Upload file:
   - Klik "Add file" -> "Upload files"
   - Drag & drop 2 file dari folder ini: index.html dan foto-reva.jpeg
   - Klik "Commit changes" (bawah)
4) Aktifkan GitHub Pages:
   - Tab "Settings" -> kiri "Pages"
   - Source: "Deploy from a branch"
   - Branch: "main"  /  Folder: "/ (root)"
   - Klik "Save"
5) Tunggu 1-2 menit, lalu link muncul:
   https://USERNAME.github.io/cv-reva/
   (ganti USERNAME dengan username GitHub Anda)

CATATAN:
- Link ini PERMANEN dan GRATIS, tidak perlu komputer menyala.
- Nama file foto harus tetap "foto-reva.jpeg" (sudah sesuai).
- Jangan rename index.html.
- Kalau mau update CV nanti: edit index.html lalu upload ulang (overwrite).
- Foto asli 33 KB - aman diupload.
